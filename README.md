⚖️ BMI Calculator (Python)

A simple command-line Body Mass Index (BMI) calculator built with Python.  
This beginner-friendly project calculates BMI from user-provided weight and height, displays the BMI value rounded to two decimals, and classifies the result into standard categories (Underweight, Normal, Overweight, Obese).



📌 Project Overview
The BMI Calculator is a console program designed to help beginners practice Python basics such as input handling, arithmetic operations, conditional statements, and formatted output. It demonstrates clear logic, basic validation, and user-friendly messaging.


 ⭐ Features
- Accepts weight (kg) and height (meters) as inputs  
- Calculates BMI using the standard formula: `BMI = weight / (height ** 2)`  
- Rounds BMI to 2 decimal places for readability  
- Classifies BMI into:
  - Underweight (BMI < 18.5)  
  - Normal weight (18.5 ≤ BMI < 24.9)  
  - Overweight (25 ≤ BMI < 29.9)  
  - Obese (BMI ≥ 30)  
- Handles basic invalid inputs (non-positive height/weight)  
- Clean console output and short explanation of category meaning
